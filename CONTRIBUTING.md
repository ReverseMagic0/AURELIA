# Contributing

1. Read `AGENTS.md` and the relevant policy before changing code.
2. Keep each change focused and explain the user or engineering outcome.
3. Add tests for behavior and invariants, not merely implementation details.
4. Run formatting, analysis, and relevant tests. Record checks that could not run.
5. Do not add dependencies, generated code, fake production paths, or speculative abstractions without justification.
6. Update authoritative documentation and project state when facts or decisions change.
7. Keep pull requests small enough to review and include risks, verification evidence, and screenshots/video for meaningful UI changes.
